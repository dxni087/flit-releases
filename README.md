# Flit — descargas y actualizaciones

Este repositorio es **público a propósito**: aloja el instalador y el canal de
actualización de [Flit](https://github.com/dxni087/Flit). El código fuente vive
en un repositorio privado porque la app se vende — publicarlo entero significaría
que cualquiera puede compilarla sin pagar.

Aquí solo hay dos cosas:

- **Releases** — el `.dmg` firmado de cada versión.
- **`appcast.xml`** — el canal que lee Sparkle dentro de la app para avisar de
  que hay versión nueva y actualizarse sola.

## Descargar

La última versión siempre está en
[Releases](https://github.com/dxni087/flit-releases/releases/latest).

Requiere macOS 15 o superior. Apple Silicon e Intel.
